🎮 Number Guessing Game (Java Swing)

## 📌 About the Project
The Number Guessing Game is a GUI-based desktop application developed using Java Swing. In this game, the computer generates a random number, and the player has to guess the correct number within a limited number of attempts.

The application provides hints to help players guess the number and offers different difficulty levels for an interactive gaming experience.

## ✨ Features
- User-friendly Graphical User Interface (GUI)
- Random number generation
- Three difficulty levels: Easy, Medium, and Hard
- Hints: Too High and Too Low
- Limited attempts for each game
- Score tracking
- Game history
- Play Again functionality
- Game Over message when attempts are exhausted

## 🛠️ Technologies Used
- Java
- Java Swing
- Java AWT
- Object-Oriented Programming (OOP)
- Random Class
- ArrayList

## ⚙️ How to Run the Project

### Prerequisites
- Java Development Kit (JDK)
- Visual Studio Code or any Java-supported IDE

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/shubhamvis-coder/NumberGuessing-Game.git
   ```

2. Open the project folder in VS Code.

3. Open the terminal inside the `src` folder.

4. Compile the Java files:

   ```bash
   javac Main.java GameFrame.java
   ```

5. Run the application:

   ```bash
   java Main
   ```
